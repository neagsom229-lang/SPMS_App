# SPMS Admin Guide

## User Management

### Add a User
1. Click "Users" in sidebar
2. Click "Add User"
3. Fill in:
   - Username
   - Password
   - Full Name
   - Role:
     - Admin: Full access
     - Manager: Limited access
     - Cashier: Basic access
4. Click "Save"

### Edit a User
1. Find the user
2. Click "Edit"
3. Update information
4. Click "Save"

### Delete a User
1. Find the user
2. Click "Delete"
3. Confirm

## Stock Management

### View Stock
1. Click "Stock" in sidebar
2. See all products with quantities

### Update Stock
1. Find the product
2. Click "Update Stock"
3. Enter new quantity
4. Click "Save"

### Low Stock Alerts
- Check "Low Stock" section on Dashboard
- Products with quantity below alert level appear

## System Settings

### General Settings
- Company name
- Currency
- Timezone
- Date format

### Payment Settings
- Stripe API keys
- Payment methods
- Tax rates

### User Settings
- Password policies
- Session timeout
- Two-factor auth

## Activity Log

### View Activity Log
1. Click "Activity" in sidebar
2. See all user actions:
   - Login attempts
   - Product changes
   - Order updates
   - User management

### Export Logs
- Click "Export" to download
- Choose CSV or Excel format

## Security

### Best Practices
1. Use strong passwords
2. Enable two-factor auth
3. Review activity logs regularly
4. Limit admin access
5. Backup data weekly

### Backup
1. Go to Settings
2. Click "Backup"
3. Choose location
4. Click "Create Backup"
